# Adolfo Rojas - Personal Portfolio

This is the source code for my personal website and portfolio, built to showcase my professional background, academic projects, and technical skills.

## Tech Stack
- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vite.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## Features
- **Portfolio Showcase**: Highlights my academic and personal projects.
- **Experience & Curriculum**: Dynamic sections detailing my professional journey and credentials.
- **Responsive Design**: Mobile-first approach optimized for all devices.
- **Dark/Light Mode**: User preference support.

## Getting Started

To run this project locally:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/AdolfoRV/adolforv.github.io.git
   cd adolforv.github.io
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start development server**:
   ```bash
   npm run dev
   ```

## Deployment
This project is configured to deploy via GitHub Pages using the `gh-pages` package:
```bash
npm run deploy
```
